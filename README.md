# Castle War — informations publiques

Pages officielles de confidentialité et de suppression des données pour Castle War,
publié par Développement Solution.

- `index.html` : accueil et contact
- `privacy.html` : politique de confidentialité
- `delete-data.html` : suppression du profil local, des données et demandes au support

Publication GitHub Pages depuis la branche `main`, dossier racine.
Aucun code du jeu, aucune sauvegarde et aucune clé de signature dans ce dépôt.
